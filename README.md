# EV Charging Station Management System

## Project Overview

The EV Charging Station Management System is a backend application designed to manage electric vehicle charging stations, users, charger availability, reservations, payments, and notifications.

## Technologies Used

* Java
* Spring Boot
* Spring Security
* MySQL
* Apache Kafka
* Redis
* Docker

## Microservices

* User Service
* Station Service
* Booking Service
* Payment Service
* Notification Service

## Architecture

The application follows a microservices architecture where different services handle different business responsibilities.

Services communicate with each other using REST APIs and Apache Kafka where required.

Redis is used for caching and fast access to frequently required data.

MySQL is used for persistent data storage.
